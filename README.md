# F1 Telemetry & PitCrew Hub

A Flutter-based mobile application prototype designed for
motorsport telemetry monitoring and pit-crew workflow management.

## Features

- Telemetry data dashboard
- Vehicle setup lookup
- Mechanical activity logging
- Dynamic configuration forms

## Tech Stack

- Flutter
- Dart
- Dio
- Repository Pattern

## Project Scope

This project explores mobile application development,
API integration, data handling, and application architecture.

## Getting Started

Install dependencies:

```bash
flutter pub get
```
